# Mais Odonto — prévia para apresentação

Aplicação React + TypeScript + Vite. Execute `npm ci`, `npm run dev`, `npm run build` ou `npm run lint` nesta pasta.

Prévia: https://luqbruno.github.io/mais-odonto-clinica-landing/

Publicação automática pelo GitHub Actions após push na main. Caminhos relativos preservam as imagens no subdiretório do GitHub Pages. A prévia mantém noindex/nofollow; publicação de demonstração não significa aprovação final da clínica.

Fontes: perfil oficial https://www.instagram.com/maisodonto_clinica/ e https://linktr.ee/maisodontoclinica. Foto do hero baseada na publicação https://www.instagram.com/p/DDppKmYSj4J/, tratada por IA a pedido de Bruno; pequenos detalhes podem ser reconstruídos. Ilustração de implantes da publicação https://www.instagram.com/p/DeSIrkSJq6X/, identificada como IA e não resultado clínico. Uso definitivo, logo, CROs, horários e endereços completos dependem de aprovação/ confirmação da clínica. Sem números, depoimentos ou promessas inventados.

Dados e canais em src/clinicData.ts; composição em src/ClinicPage.tsx; tokens em src/ClinicPage.css. Não há coleta por formulário, analytics ou pixels. Registros internos e materiais originais permanecem fora deste repositório público.
